# لوحة المالية لمجموعة المكاتب

لوحة مالية تحليلية باللغة العربية (RTL) لمجموعة تضم شركتين: مكتب محاماة وشركة خدمات أعمال. تربط الرواتب والخدمات والتأجير والمصروفات والمبيعات في نموذج واحد، وتُخرج قائمة الدخل والتدفق النقدي والتوقعات والسيناريوهات.

> البيانات المرفقة **مُنقّحة**: الأسماء استُبدلت، والأرقام الحساسة حُذفت. الأرقام المالية حقيقية. انظر [docs/DATA.md](docs/DATA.md).

## الميزات

- **لوحة المؤشرات**: الإيرادات والربح والتكاليف والإشغال ونقطة التعادل، ومقارنة الشركتين.
- **المبيعات**: إجمالي شهري تقديري مع نطاق (150 إلى 300 ألف)، وتفصيل حسب الخدمة بالكمية.
- **الخدمات وتسعيرها**: السعر والتكلفة المباشرة وتكلفة العمل الداخلي وهامش كل خدمة.
- **الموظفون والرواتب**: التكلفة الكاملة لكل موظف، بالشهر واليوم والساعة والساعة المنتجة، مع الإضافي والتأمين.
- **التأجير**: الوحدات والعقود والإشغال، وتكلفة المالك وإيراد المستأجر لكل وحدة.
- **المصروفات**: بنود شهرية قابلة للتعديل.
- **قائمة الدخل**: شهرية وسنوية ولفترة مختارة، مع الضريبة وهامش الربح.
- **التدفق النقدي والتوقع**: رصيد شهري، ونقطة التعادل وهامش الأمان، وتوقع خمس سنوات.
- **السيناريوهات**: معاملات للكمية والسعر والتكلفة والإشغال، ومقارنة النتائج جنباً إلى جنب.
- **التصدير**: Excel بمعادلات حية، وCSV لكل جدول، وPDF عبر الطباعة، ونسخة احتياطية JSON.
- **فحص جودة البيانات**: يكشف النقص والتعارض (مساحات، أسعار صفرية، وحدات بلا عقد).

## التشغيل

المتطلبات: Node.js 20 أو أحدث.

```bash
npm install
npm run dev        # الخادم المحلي
npm test           # الاختبارات (منطق الحساب والتصدير والنسخ الاحتياطي)
npm run build      # فحص الأنواع ثم البناء
```

## كيف يعمل الحساب

```
src/lib/
  types.ts          أنواع البيانات
  finance.ts        قائمة الدخل الشهرية، والتجميع، والتدفق، والتوقع، ونقطة التعادل
  labor.ts          تكلفة الموظف والساعة والإنتاجية والإضافي
  services.ts       تسعير الخدمة وهوامشها
  rentals.ts        عقود الوحدات، وإيراد المستأجر، وتكلفة المالك
  expenses.ts       مصروف كل شهر
  share.ts          نسبة الشركة من البند المشترك
  dataQuality.ts    فحوص جودة البيانات
  excelExport.ts    مصنف Excel بمعادلات حية وقيم محسوبة
  backup.ts         تصدير الاستيراد والتحقق من الشكل
  store.ts          الحالة (Zustand) مع الحفظ المحلي
```

القواعد الكاملة والافتراضات في [docs/ASSUMPTIONS.md](docs/ASSUMPTIONS.md).

## الخصوصية

كل شيء يعمل في المتصفح. لا يُرسل أي شيء إلى خادم. البيانات تُحفظ في `localStorage` لجهازك فقط.
